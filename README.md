# 짤·카드 스튜디오 (T03)

로그인 없이 PNG·JPEG 이미지와 문구를 편집해 1:1, 4:5, 9:16 PNG를 만드는 정적 웹 앱입니다.

## 실행

`docs/`를 정적 서버로 제공하세요. 예: `python3 -m http.server 8765 --directory docs`. GitHub Pages는 `main` 브랜치의 `/docs`를 배포합니다.

## 주요 동작

- 업로드 파일의 PNG/JPEG 시그니처·크기·디코딩을 확인합니다. 실패하면 현재 편집 내용을 유지하고 이유를 표시합니다.
- 이미지 입력과 JSON 복원 이미지는 캔버스로 다시 그려 메타데이터를 제거합니다. 업로드한 원본은 서버로 보내지 않습니다.
- 미리보기의 실제 1080px 캔버스를 그대로 PNG로 내보냅니다. 비율 변경 시 같은 좌표와 줄바꿈 함수를 사용합니다.
- 템플릿은 IndexedDB에 안정된 ID로 저장합니다. 새로 만들기·불러오기·수정·삭제·새로고침 유지가 됩니다.
- JSON 가져오기는 전체 항목과 이미지를 검증한 후 한 트랜잭션으로 교체합니다. 잘못된 파일은 목록을 유지합니다.
- 완성 이미지 3개는 `docs/examples/`에 있으며, 제작·권한 기록은 `examples/SOURCE.md`에 있습니다.

## 점검

`node tests.mjs`로 극단 입력 12건과 이모지 줄바꿈 회귀 검사를 실행했습니다. 상세 기록은 `evidence/extreme-inputs.md`에 있습니다. 코드 문법, PNG 3개의 크기·파일 열기·EXIF 항목 부재, 정적 서버의 HTML/PNG 응답을 검사했습니다. Chromium 브라우저에서 업로드·템플릿 CRUD와 새로고침·JSON 복원·세 비율 화면/파일 대조도 확인했습니다. 실행 내용은 `evidence/browser-qa.md`에 있습니다.
