# Chromium 브라우저 검사

2026-10-16. 로컬 정적 서버에서 `docs/`를 제공하고 Chromium의 실제 캔버스·IndexedDB·다운로드를 Playwright로 조작했습니다. 임시 브라우저 프로필에서 실시했습니다.

| 검사 | 결과 |
| --- | --- |
| PNG·JPEG 업로드와 미지원 파일 거부 후 기존 캔버스 유지 | PASS |
| 문구·위치·크기·색 입력마다 미리보기 즉시 변경 | PASS |
| 1:1 미리보기 캔버스와 다운로드 PNG | PASS: 1080 × 1080, RGBA 픽셀 SHA-256 일치 |
| 4:5 미리보기 캔버스와 다운로드 PNG | PASS: 1080 × 1350, RGBA 픽셀 SHA-256 일치 |
| 9:16 미리보기 캔버스와 다운로드 PNG | PASS: 1080 × 1920, RGBA 픽셀 SHA-256 일치 |
| 템플릿 3개 생성·불러오기·수정·삭제 및 각 단계 새로고침 유지 | PASS |
| 손상 JSON·필수 누락 JSON 거부 후 기존 템플릿 유지 | PASS |
| 정상 JSON 내보내기·다시 가져오기, 별도 정상 JSON 3개 복원·새로고침 | PASS |
| 브라우저 JavaScript 오류 | 0건 |

같은 판정은 캔버스 `getImageData()`의 RGBA 바이트와 다운로드 PNG를 열어 얻은 RGBA 바이트의 SHA-256을 비교했습니다. 따라서 이미지 잘림, 문구 좌표, 줄바꿈을 포함한 최종 픽셀이 세 비율 모두 일치합니다. 테스트에는 가로 JPEG와 한글·영문·이모지·명시적 줄바꿈 문구를 사용했습니다.

JSON을 연달아 가져올 때 앞선 비동기 작업이 뒤늦게 목록을 덮을 수 있는 결함을 검사 중 발견했습니다. 가져오기 처리가 끝날 때까지 파일 입력을 비활성화한 뒤 동일 순서로 재검사해 통과했습니다.
