가져오기 전에 모든 항목을 검사합니다. 정상 파일이면 현재 목록을 교체합니다. 잘못된 파일은 기존 목록을 유지합니다.

HOW TO USE

3단계로 완성하세요.

  1. 이미지를 불러오고 문구를 적습니다.
  2. 위치·크기·색·비율을 보면서 조정합니다.
  3. PNG를 내려받거나 템플릿으로 저장합니다.
SAFE BY DESIGN

내 이미지, 내 브라우저.

이미지는 이 브라우저에서 다시 그려 메타데이터를 제거합니다. 저장한 템플릿은 이 브라우저의 로컬 저장소에만 남습니다. 타인의 이미지·개인정보·비밀값은 공개 카드에 넣지 마세요.
